Entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311): a program that writes one short text to `/output/entry.txt`, written to intrigue the AI judge reading it.

## Run

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the entry text deterministically to `/output/entry.txt` (1–280 characters).
